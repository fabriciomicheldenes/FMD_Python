Guia rápido — criar venv e gerenciar pacotes com pip

Este é um roteiro simples para criar um ambiente virtual (venv), instalar pacotes com pip e salvar/recuperar dependências com requirements.txt.

1) Criar a pasta do projeto (exemplo)

# no seu terminal
mkdir -p FMD_Python/Games/Megamania
cd FMD_Python/Games/Megamania

2) Criar o ambiente virtual

# cria a pasta .venv com o interpretador atual
python -m venv .venv

3) Ativar o ambiente virtual

Depois de ativar, o prompt mostra o nome do ambiente (ex.: (.venv)).

# Linux / macOS
source .venv/bin/activate

# Windows (PowerShell)
.venv\Scripts\Activate.ps1

# Windows (cmd.exe)
.venv\Scripts\activate.bat

4) Instalar pacotes com pip

# exemplo: instalar requests
pip install requests

# instalar uma versão específica
pip install requests==2.31.0

5) Ver pacotes instalados

pip list
# ou
pip show nome_do_pacote

6) Salvar dependências (criar requirements.txt)

# gera requirements.txt com versões fixas
pip freeze > requirements.txt
Dica: salve sempre o requirements.txt no controle de versão (git) para reproduzir o ambiente em outra máquina.

7) Recriar o ambiente em outra máquina

# no destino
python -m venv .venv
source .venv/bin/activate   # ou equivalente no Windows
pip install -r requirements.txt

8) Desativar o ambiente

deactivate

9) Exemplo mínimo de .gitignore para projetos Python

.venv/
__pycache__/
*.pyc
.env

10) Fluxo sugerido (resumido)

  • Criar pasta do projeto
  • python -m venv .venv
  • Ativar, instalar pacotes com pip
  • pip freeze > requirements.txt
  • Commitar código + requirements.txt
